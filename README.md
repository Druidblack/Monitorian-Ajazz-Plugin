# Monitorian-Ajazz-Plugin
Плагин для регулировки яркости монитора через приложение Monitorian

# Возможности
 * Регулировка яркости монитора (мониторов)
 * Отображение текущего уровня яркости
 * Поддерживает управление кнопками и энкодером

# Для работы нужно приложение [Monitorian](https://github.com/emoacht/Monitorian) установленное из Microsoft Store

# Для установки скачайте релиз и распакуйте папку по пути

````
C:\Users\USERNAME\AppData\Roaming\HotSpot\StreamDock\plugins
````
